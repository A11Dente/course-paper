# Соревнования — мобильное приложение (Android, Kotlin, Jetpack Compose, Room/SQLite)

## Как открыть
1. Android Studio → File → Open → выбрать папку `Sportik` (где лежит `settings.gradle.kts`).
2. Дождаться Gradle Sync (нужен интернет). Если Studio предложит обновить Android Gradle Plugin — соглашайтесь.
3. Запустить на эмуляторе или телефоне (Android 8.0 / API 26 и выше).

## Структура
- `app/src/main/java/com/example/sportik/data` — таблицы (Entities.kt), запросы и «хранимые процедуры» (AppDao.kt), БД (AppDatabase.kt)
- `app/src/main/java/com/example/sportik/ui` — экраны Compose, ViewModel, навигация
- `app/src/main/assets/db` — `seed.sql` (начальные данные) и `triggers.sql` (триггеры), выполняются при первом запуске
- `sql/` — те же скрипты в читаемом виде + `schema.sql` (для Приложения 1 пояснительной записки)

## Как устроены экраны
- **Турниры** → турнир → весовые категории турнира (добавление и правка категорий)
- **Поединки** → турнир → весовая категория → выбор двух участников
- **Результаты** → турнир (раскрывается) → поединок → внесение или изменение результата (победитель из двух участников, способ, раунд)

## Сброс базы данных
Удалить приложение с устройства/эмулятора (или очистить данные приложения) и запустить заново:
данные и триггеры создаются заново. При обновлении с прежней версии база мигрирует автоматически (миграция 1 → 2).
